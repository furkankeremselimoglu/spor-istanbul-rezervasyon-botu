# Güvenlik Politikası

## Bir güvenlik açığı bildirmek

Bir güvenlik açığı bulduysanız **lütfen GitHub Issues üzerinden herkese açık bir şekilde paylaşmayın**.

Bunun yerine, genel depoda GitHub'ın özel güvenlik açığı bildirim özelliğini kullanın:

1. [spor-istanbul-rezervasyon-botu](https://github.com/furkankeremselimoglu/spor-istanbul-rezervasyon-botu) deposuna gidin
2. **Security** sekmesi → **Report a vulnerability** düğmesine tıklayın
3. Açığı mümkün olduğunca ayrıntılı açıklayın (nasıl tetiklendiği, etkisi, varsa bir örnek)

Bildiriminiz yalnızca repo sahibiyle paylaşılır ve herkese açık hale gelmez.

## Kapsam

Kapsam içinde: bu uygulamanın kodu (`bot.py`, `app.pyw`, `src/`, kurulum betikleri, otomatik güncelleme mekanizması).

Kapsam dışında: **online.spor.istanbul** sitesinin kendisi — sitedeki bir açığı bu depoya bildirmeyin, İBB'ye iletin.

## Ödül programı

Bir ödül (bug bounty) programı yoktur. Bildirimler gönüllü olarak değerlendirilir.
